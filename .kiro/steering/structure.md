# Project Structure

```
icon-grid-unlimited/
├── icon-grid-unlimited.php   # Plugin entry point — block registration & render callback
├── package.json              # npm config (build scripts, dependencies)
├── src/                      # Source files (compiled by @wordpress/scripts)
│   ├── block.json            # Block metadata, attributes schema, asset references
│   ├── index.js              # Block registration entry point
│   ├── edit.js               # Gutenberg editor component (InspectorControls, modals, grid editor)
│   ├── save.js               # Save component (returns null — dynamic server-side render)
│   ├── view.js               # Frontend script (animations, hover, IntersectionObserver, global API)
│   ├── editor.scss            # Editor-only styles
│   └── style.scss             # Frontend styles (grid layout, cells, SVG layers, accessibility)
├── includes/                  # PHP server-side rendering templates
│   ├── render.php             # Main frontend render template
│   └── render_clean.php       # Alternate render template (similar structure)
├── build/                     # Compiled output (generated by `npm run build`, gitignored)
└── node_modules/              # Dependencies (gitignored)
```

## Architecture Notes

- The block uses a 12-column storage layout internally (max 12×12 = 144 tiles). Storage index = `row * 12 + col`. The visible grid is a subset defined by `gridRows` × `gridCols`.
- `edit.js` is the largest file (~1700 lines). It contains the full editor UI: grid size controls, timing/line/icon style panels, a visual grid editor modal, animation rounds editor, per-tile settings, and block tile embedding.
- `view.js` is a self-contained IIFE that initializes all grids on the page. It uses DOM caching, geometry caching, a line pool pattern, and path length caching for performance.
- `render.php` generates scoped CSS (using a unique `block_id`), the grid HTML with SVG icons, expansion tiles for enlarge mode, and Schema.org JSON-LD structured data.
- Attributes are defined in `block.json` with defaults. The `config` attribute is a nested object holding all animation/style parameters.
- Two SVG layers per tile: `.icon-grid-wireframe` (stroked, visible by default) and `.icon-grid-gradient` (filled, shown on hover/highlight).
